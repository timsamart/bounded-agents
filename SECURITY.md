# Security

This repository publishes a manuscript and build scripts. It is not a
runtime product and does not accept production credentials or customer data.

## Reporting a problem in this repo

If you find a vulnerability in the build tooling, CI workflow, or any script
shipped here, open a private GitHub security advisory on
[timsamart/bounded-agents](https://github.com/timsamart/bounded-agents/security/advisories/new)
or email **timmy@timosam.com**.

Please do not open a public issue for a tool vulnerability until it is fixed
or we ask you to.

## Design claims in the manuscript

Disagreement with an architectural claim belongs in an ordinary issue or PR,
not a security advisory.
