# Appendix C. Threat model and method {#appendix-c}

Threat set for a hostile model with real tools; method for regenerating threats when the set ages.

## Primary adversary {#a-3-1}

An attacker who can shape inputs the agent reads (documents, web, email, tool descriptions, memory) and who needs one successful instruction to act with the agent's held authority.

## Method {#a-3-2}

Derive threats from invariants I1 to I8. A threat that does not falsify an invariant is out of scope for this register. Refresh when a protocol, vendor, or regulation changes an assumption named in an ADR reopen trigger.
