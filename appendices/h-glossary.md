# Appendix H. Glossary {#appendix-h}

Terms that the field uses in two senses; this document picks one and names the other.

## Dual-sense terms {#a-8-1}

Agent (workload versus natural person). Authority (envelope versus IAM role). Policy (allow-list derivation versus business rule text). Memory (governed store versus model weights). Gateway (mediation seam versus API management product).
